# KPI tracking notes

Planned metrics for the survey insight workflow:

- Auto-classification rate: percent of comments classified without human review
- Escalation rate: percent of comments flagged for human review
- Theme volume: count of comments per theme (Food, Membership, Operations, Staff, Cleanliness)
- Sentiment mix: percent positive, neutral, negative per period
- Manager review turnaround: average time from flag to resolution

These metrics can be tracked manually in Excel/Power BI as a lightweight dashboard, using the `needs_human_review`, `theme`, and `sentiment` fields from the sample dataset.
